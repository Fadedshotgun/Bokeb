Bokeb is a simple C-based programming language that uses the Belarusian language instead of English

The name is based off my name (Autumn) translated to Belarusian (восень)

цэлы - int
для - for
друкаваць - print
пакуль - while
калі - if
інакш - else

The entry point of all programs must be нічога асноўны()
